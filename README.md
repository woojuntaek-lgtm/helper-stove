# 마음 난로 온도계

내 도움은 곁을 데우는 **난로**일까, 과열된 **불씨**일까? 에니어그램 2번(조력가) 이야기를 바탕으로, 누구나 1분 만에 자신의 "도움 습관"을 점검하고 주변의 따뜻한 사람에게 고마움을 전할 수 있는 앱입니다. 「에니어그램 2번 조력가」 강의 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/helper-stove/**

## 특징
- ♨️ 온도계: 12문장 1~5점 → 따뜻함·과열·연료(자기 돌봄) 세 온도와 난로 상태(따뜻한 난로 / 불씨 주의 / 연료가 필요한 난로 / 은은한 손난로 / 숨 고르는 불), 맞춤 한 줄 처방
- 🤝 묻고 돕기: 일상 상황 6가지에서 "오래가는 도움" 고르기(2번 입장 + 2번 곁의 사람 입장), 해설 포함
- 💌 고마움 카드: "덕분에 ○○가 편해졌어요" 형식의 구체적 감사 문구 만들기 → 복사·공유
- 🔥 2번 한눈에: 한 줄 정의, 동양 수리(火·丁·남·빨강), 난로와 불씨, 날개, 스트레스·성장 방향, 건네는 말

성찰을 돕는 참고용이며 심리검사나 전문 상담을 대신하지 않습니다. 입력 내용은 기기 밖으로 나가지 않습니다.
